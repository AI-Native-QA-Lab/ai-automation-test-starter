## 关键安全边界

- Provider 建议不是执行证据；只有注入的原生 runner 结果可以产生 execution evidence。
- Build 不自行覆盖文件，文件变更必须由宿主显式提供 `applyChange` 回调。
- 生成或修复变更在原生执行前必须有显式 review 回调；没有 review 不会宣称已验证。
- Build 的迭代次数和工具调用次数分别受预算约束；环境不可用与疑似产品缺陷不会被盲目修复。
- Learn Mode 默认不返回完整测试方案；Provider 越权返回 solution 时会被拒绝。
- 未知失败保持 `unknown`，不把每个失败都归因于测试代码。
- 没有真实 API target、凭据或外部模型调用时，不生成伪造目标、凭据或结果。
