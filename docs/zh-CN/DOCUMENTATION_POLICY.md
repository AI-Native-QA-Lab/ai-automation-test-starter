# 文档与本地化策略

> [English（规范文档）](../i18n/DOCUMENTATION_POLICY.md) · 简体中文

## 规范语言

English 是 README、架构、契约、API/CLI 参考、AGENTS、贡献文档和 release notes 的规范语言。

## 中文文档

简体中文是一级本地化语言。中文文档放在 `docs/zh-CN/`，通过入口链接与英文规范文档切换。

## 同步规则

中文本地化可以调整解释方式，但不能改变命令、契约语义、默认行为、质量阈值或支持状态。项目过程记录可以使用中文；代码标识符、公共契约和项目 API 使用英文。

## 当前范围

v0.1 先维护中文 README、项目章程、MVP 计划和本地化策略。新增公共契约时，必须在同一变更中更新英文规范文档和对应中文本地化内容。
